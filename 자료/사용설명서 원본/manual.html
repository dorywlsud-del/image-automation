1시작하기 전에

해냄에듀 책 미리보기는 인쇄용 펼침 표지 PDF(뒤표지 · 책등 · 앞표지가 한 장에 있는 파일)를 넣으면, 재단선을 찾아 크기를 맞추고 실제 책처럼 보이는 3D 목업 이미지를 만들어 주는 도구입니다.

준비물

항목내용
프로그램 파일해냄에듀 책 미리보기.html 파일 하나만 있으면 됩니다. 설치가 필요 없습니다.
브라우저크롬(Chrome) 또는 엣지(Edge) 최신 버전을 권장합니다.
인터넷 연결3D 화면과 PDF 읽기 기능을 인터넷에서 불러오므로 연결되어 있어야 합니다.
표지 파일펼침 표지 PDF (재단선 포함 출력 권장). JPG · PNG 이미지도 사용할 수 있습니다.

실행 방법

HTML 파일을 더블클릭하면 기본 브라우저에서 열립니다. 처음에는 백지 책이 보이며, 여기에 표지 파일을 넣으면 바로 그 표지로 바뀝니다.

파일은 어디에도 올라가지 않습니다표지 PDF는 내 컴퓨터의 브라우저 안에서만 처리됩니다. 외부 서버로 전송되지 않으므로 출간 전 표지도 안심하고 사용할 수 있습니다.

25분 만에 목업 만들기

가장 흔한 경우(재단선이 있는 무선 제본 표지)는 아래 다섯 단계면 끝납니다.

  1. 표지 PDF 넣기 — 왼쪽 위 점선 상자에 PDF를 끌어다 놓거나, 상자를 클릭해 파일을 고릅니다.
  2. 재단 정보 확인 — 초록색 “자동 감지 완료”가 뜨고, 앞표지 폭 · 높이 · 책등 폭이 실제 판형과 맞는지 봅니다.
  3. 제본 방식 선택 — 무선 / 양장 / 중철 중 해당하는 것을 누릅니다. (기본값: 무선)
  4. 구도 고르기 — “3. 목업 연출”에서 세워서 · 눕혀서 · 쌓아서 등을 고르고, 화면을 마우스로 돌려 각도를 맞춥니다.
  5. PNG로 저장 — 맨 아래 PNG로 저장 버튼을 누르면 이미지가 다운로드 폴더에 저장됩니다.
숫자가 이상하면?앞표지 폭이 지나치게 크거나 앞 · 뒤표지 폭이 다르면 날개나 싸바리가 섞인 것입니다. 7장(재단선 확인 화면)에서 영역을 다시 그리면 바로 해결됩니다.

3화면 구성

왼쪽은 설정 패널, 오른쪽은 결과 화면입니다. 오른쪽 위 탭으로 3D 목업과 재단선 확인 화면을 오갑니다.

영역하는 일
1. 표지 파일PDF · 이미지를 넣는 곳. 여러 페이지 PDF는 페이지를 고를 수 있고, 이미지는 해상도(dpi)를 입력합니다.
2. 재단 정보감지 결과(앞표지 폭 · 높이 · 책등 폭), 제본 방식, 크기 지정 방식, 제본 방향을 정합니다.
3. 목업 연출구도 8종, 표지 마감(무광 · 반광 · 유광), 배경, 그림자, 조명, 자동 회전.
4. 이미지 저장저장 크기(화면의 1~4배)를 고르고 PNG로 저장합니다.
3D 목업 탭완성된 책을 마우스로 돌리고(드래그) 확대 · 축소(휠)합니다.
재단선 확인 탭PDF 위에 인쇄 영역과 책등이 표시됩니다. 드래그로 직접 고칠 수 있습니다.

4표지 파일 넣기

점선 상자에 파일을 끌어다 놓거나 상자를 클릭해서 고릅니다. 화면 어디에 끌어다 놓아도 됩니다.

가장 잘 되는 PDF

  • 뒤표지 · 책등 · 앞표지(+날개)가 한 페이지에 펼쳐진 파일
  • 인디자인 · 일러스트레이터에서 재단선(크롭 마크) 포함으로 출력한 파일
  • 책등 위아래에 접지선 표시가 있으면 책등 폭까지 정확히 잡힙니다.
  • 날개가 있다면 날개 접힘 위치에도 표시가 있으면 좋습니다.

JPG · PNG 이미지

이미지는 실제 크기 정보가 없어서 이미지 해상도(dpi) 칸에 원본 해상도를 넣어야 mm 값이 맞습니다. (기본 300dpi) 3D 모양 자체는 비율만 쓰므로 dpi가 달라도 목업은 똑같이 나옵니다.

여러 페이지 PDF페이지가 2장 이상이면 “페이지” 선택 칸이 나타납니다. 펼침 표지가 있는 페이지를 고르세요.

5재단 정보 읽는 법

파일을 넣으면 프로그램이 재단선을 찾아 앞표지 · 책등 · 뒤표지를 나눕니다. 결과는 색깔 상자로 알려 줍니다.

상자 색뜻할 일
■ 초록 · 자동 감지 완료재단선을 찾아서 크기를 맞췄습니다. 날개 · 싸바리를 뺐다면 그 내용도 함께 적힙니다.숫자가 판형과 맞는지만 확인
■ 주황 · 확인 필요일부를 추정했습니다. (예: 책등 접지선이 없어 색 경계로 책등을 추정, 재단선이 없어 PDF 정보로 크기를 정함)재단선 확인 화면에서 눈으로 확인하고 필요하면 수정
■ 빨강파일을 열지 못했거나 입력값이 잘못되었습니다.메시지 내용을 확인

프로그램이 크기를 찾는 순서

  1. 재단선 표시 — PDF 여백에 있는 가는 검은 선을 찾습니다. 일본식 이중 재단선, 가운데 맞춤 표시(십자 원)도 알아서 걸러냅니다.
  2. PDF 재단 영역(TrimBox) — 재단선이 없으면 PDF 안에 저장된 재단 크기 정보를 씁니다.
  3. 그림 영역 − 도련 — 그것도 없으면 그림이 있는 범위에서 도련(기본 3mm)만큼 안쪽을 씁니다.

책등은 접지선 표시 → 가운데 부근의 색 경계 → 입력한 책등 폭 순서로 찾습니다.

제본 방향

좌철(일반)은 가로쓰기 책처럼 펼침면 오른쪽이 앞표지입니다. 세로쓰기 책처럼 왼쪽이 앞표지인 경우 우철을 누르세요.

6제본 방식: 무선 · 양장 · 중철

“제본 방식” 버튼을 바꾸면 같은 PDF를 그 방식에 맞게 다시 해석하고, 3D 모양도 바뀝니다.

방식3D 모양재단선 해석
무선일반 소프트커버. 표지와 내지가 같은 크기.책등 접지선 양옆을 앞 · 뒤표지로, 그 바깥 표시가 있으면 날개로 보고 뺍니다.
양장두꺼운 판지 표지, 내지보다 큰 표지, 책등 옆 홈, 머리띠. 각양장(평평한 책등) / 환양장(둥근 책등).판지 뒤로 접혀 들어가는 싸바리를 빼고, 책등 옆 홈 표시를 찾습니다. 날개가 있는 커버(자켓)면 날개를 빼고 싸바리는 빼지 않습니다.
중철얇은 책자. 책등 없이 접힌 부분이 둥글고 스테이플 2개.가운데 접지선 하나를 기준으로 좌우를 나눕니다. 날개 표시가 있으면 뺍니다.

양장 설정

항목설명 (기본값)
책등 모양각양장 / 환양장
싸바리 접힘판지 뒤로 접혀 들어가는 여백. 접힘 표시가 없을 때 재단선에서 이만큼 안쪽을 표지 끝으로 봅니다. (15mm)
홈 폭책등과 판지 사이 오목한 부분. 표시가 있으면 자동으로 채워집니다. (8mm)
판지 두께3D 표지 두께 (2.5mm)
표지가 내지보다 큰 폭표지가 내지보다 튀어나온 정도 (3mm)

중철 설정

항목설명 (기본값)
페이지 수표지를 포함한 전체 쪽수 (32)
종이 두께한 장의 두께, mm (0.1)

책 두께는 페이지 수 ÷ 2 × 종이 두께로 계산되어 오른쪽 위 “두께” 칸에 표시됩니다. 예) 32쪽 × 0.1mm → 1.6mm

중철은 눕혀서 · 쌓아서 구도가 자연스럽습니다얇은 책자는 세워 두면 종이처럼 보이기 쉽습니다.

7재단선 확인 화면에서 직접 맞추기

“재단선 확인” 탭(또는 왼쪽의 재단선 확인 · 수정하기 버튼)을 누르면 PDF 위에 분홍 선(인쇄 영역)과 파란 점선(책등)이 보입니다. 어두운 부분은 목업에 쓰이지 않는 곳입니다.

날개를 빼는 가장 쉬운 방법: 영역 새로 그리기

  1. 오른쪽 위 ▭ 영역 새로 그리기 버튼을 누릅니다.
  2. 뒤표지 왼쪽 위 모서리에서 앞표지 오른쪽 아래 모서리까지 드래그합니다. 드래그하는 동안 커서 옆에 치수가 표시됩니다.
  3. 손을 떼면 그린 사각형만 남고 날개는 빠집니다. 책등은 지금 폭 그대로 가운데에 놓입니다.
  4. 필요하면 아래 표의 방법으로 미세하게 맞춥니다. 3D 목업은 즉시 바뀝니다.
다른 PDF를 열면드래그로 맞춘 값은 그 파일에만 적용됩니다. 새 파일은 다시 자동 감지합니다. 같은 판형을 계속 쓰려면 8장의 “직접 입력”을 쓰세요.

마우스 · 키보드 조작

분홍 선 · 모서리 □ 드래그크기를 바꿉니다.

숫자로 맞추고 싶다면왼쪽 “재단선 위치 직접 입력 (mm)”을 펼치면 각 선의 위치를 PDF 왼쪽 위 모서리 기준 mm로 입력할 수 있습니다.

8크기를 숫자로 직접 입력하기

“크기 지정”을 직접 입력으로 바꾸면 재단선과 상관없이 입력한 크기로 자릅니다. 판형을 정확히 알고 있을 때 가장 확실한 방법입니다.

  1. “크기 지정”에서 직접 입력을 누릅니다.
  2. 판형을 고르거나(신국판, 국판 · A5, 4×6판, 크라운판, B5, 4×6배판, A4 등) 앞표지 폭 · 높이를 입력합니다.
  3. 책등 폭을 입력합니다. (중철은 칸이 없습니다)
  4. 값을 바꾸면 바로 반영됩니다. 위치가 어긋나면 책등 중심 위치를 고치거나 펼침면 정가운데로 맞추기를 누르세요.
  • 책등(중철은 접지선) 중심에서 좌우로 앞 · 뒤표지 폭만큼만 쓰고, 바깥의 날개 · 싸바리는 모두 빠집니다.
  • 양장의 앞표지 폭은 홈을 포함한 폭입니다.
  • 직접 입력 상태로 새 파일을 열어도 입력한 크기는 유지되고, 중심 위치만 새 파일에서 다시 찾습니다. 같은 판형 시리즈를 연달아 만들 때 편합니다.
  • 재단선 확인 화면에서 드래그하면 입력 칸의 숫자도 같이 바뀝니다.

9목업 연출

구도 버튼을 누르면 카메라가 부드럽게 이동합니다. 그다음 3D 화면을 드래그해서 돌리고, 휠로 확대 · 축소해 원하는 각도를 만드세요.

설정설명
표지 마감무광 · 반광 · 유광. 유광은 빛 반사가 강해집니다.
배경색 동그라미를 누르거나 오른쪽 네모로 원하는 색을 고릅니다.
투명 배경배경 없이 책만 저장합니다(PNG). 그림자는 남습니다.
그림자바닥 그림자 진하기
조명 방향빛이 오는 방향을 좌우로 바꿉니다.
자동 회전책이 천천히 돌아갑니다(화면 확인용).

10이미지로 저장하기

  1. 3D 화면에서 원하는 구도를 만듭니다. 화면에 보이는 그대로 저장됩니다.
  2. “크기”에서 배율을 고릅니다.
  3. PNG로 저장을 누르면 다운로드 폴더에 저장되고, 아래에 실제 픽셀 크기가 표시됩니다.
크기용도
화면 크기 ×1메신저 · 빠른 공유
×2 (기본)웹 상세페이지 · SNS
×3큰 배너
×4 (인쇄용)보도자료 · 인쇄물 (컴퓨터 사양에 따라 최대 8192px로 제한)

파일 이름은 “표지파일이름_목업_구도.png”로 자동으로 붙습니다. 예) 신간표지_목업_세워서.png

상세페이지용 팁투명 배경 + ×2로 저장하면 디자인 프로그램에서 어떤 배경 위에든 바로 올릴 수 있습니다.

11자주 묻는 질문

이럴 때이렇게 하세요
날개가 표지에 같이 붙어 나와요날개 접힘 표시가 없는 PDF입니다. 재단선 확인 → 영역 새로 그리기로 앞 · 뒤표지만 감싸거나(7장), 직접 입력으로 판형을 넣으세요(8장).
양장인데 표지 가장자리가 잘려요 / 남아요양장 설정의 싸바리 접힘 값을 실제 값으로 바꾸세요. 날개 접힘 표시가 있는 커버(자켓) PDF라면 싸바리는 빼지 않고 날개만 빠집니다.
책등 위치나 폭이 어긋나요재단선 확인 화면에서 파란 점선을 끌거나, 책등 띠를 끌어 옮기세요. “좌우 대칭”을 켜 두면 폭이 양쪽으로 같이 바뀝니다.
앞 · 뒤표지 폭이 다르다고 나와요한쪽에만 날개가 있거나 재단선을 잘못 찾은 경우입니다. 재단선 확인 화면에서 확인하세요.
3D 화면이 하얗게 나오거나 안 떠요인터넷 연결을 확인하고 새로고침(F5)하세요. 크롬 · 엣지 최신 버전을 쓰세요.
색이 인쇄물과 조금 달라요인쇄용 CMYK PDF를 화면용(RGB)으로 바꿔 보여 주기 때문에 생기는 차이입니다. 목업 이미지 용도에는 문제가 없지만, 색이 중요하면 RGB로 내보낸 PDF나 JPG를 넣어 보세요.
표지 글자가 흐려요저장 크기를 ×2 이상으로 하고, 카메라를 너무 멀리 두지 마세요. 이미지 파일을 넣었다면 더 큰 원본을 쓰세요.
세로쓰기 책이라 앞뒤가 바뀌어요제본 방향을 우철로 바꾸세요.
처음 화면(백지)으로 돌아가고 싶어요새로고침(F5)하면 처음 상태로 돌아갑니다.
